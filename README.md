# Hospital IT Desk — Hospital IT Management & Support Portal
### হাসপাতাল আইটি ম্যানেজমেন্ট অ্যান্ড সাপোর্ট পোর্টাল

**Version:** 3.0 (Static Edition)  
**Target Platform:** GitHub Pages (Static Hosting)  
**Stack:** HTML5, CSS3, Vanilla JavaScript (ES6+ Modules), Bootstrap 5, Bootstrap Icons, Chart.js, IndexedDB  
**Primary Language:** বাংলা (Bangla)  
**Additional Language:** English  
**Timezone:** Asia/Dhaka  
**Currency:** BDT (৳)

---

## 1. Project Overview (প্রজেক্ট পরিচিতি)

**Hospital IT Desk** হলো একটি হাসপাতালের অভ্যন্তরীণ আইটি ডিপার্টমেন্টের দৈনন্দিন কাজ, টিকিট, সরঞ্জাম (Asset), নেটওয়ার্ক, সিসিটিভি, সফটওয়্যার লাইসেন্স, ডাটাবেজ ব্যাকআপ রেজিস্টার এবং প্রতিরোধমূলক রক্ষণাবেক্ষণ কার্যক্রম পরিচালনা করার একটি আধুনিক, রেসপনসিভ ও ক্লায়েন্ট-সাইড পোর্টাল।

এটি কোনো হাসপাতাল ম্যানেজমেন্ট সিস্টেম (HMS), পেশেন্ট ম্যানেজমেন্ট বা ক্লিনিক্যাল সিস্টেম নয়। এটি হাসপাতালের আইটি প্রকৌশলী ও কর্মচারীদের অভ্যন্তরীণ অপারেশনাল পোর্টাল।

এই সংস্করণটি সম্পূর্ণ ফ্রন্টএন্ড-অনলি আর্কিটেকচারে তৈরি। এতে কোনো পিএইচপি, মাইএসকিউএল, নোড বা ব্যাকএন্ড সার্ভার প্রয়োজন হয় না। সমস্ত ডেটা সরাসরি ব্যবহারকারীর ব্রাউজারের **IndexedDB**-তে সংরক্ষিত থাকে।

## 2. Key Features & All 14 Modules (সম্পূর্ণ ১৪টি মডিউল)

1. **Dashboard (ড্যাশবোর্ড):** IndexedDB-র লাইভ ডেটার ভিত্তিতে মোট সরঞ্জাম, ওপেন টিকিট, ক্রিটিকাল ইস্যু, রক্ষণাবেক্ষণ সতর্কতা, ব্যাকআপের ফলাফল, Chart.js চার্ট এবং সাম্প্রতিক অ্যাক্টিভিটি লগ।
2. **IT Support Tickets (টিকিট ও অভিযোগ ব্যবস্থাপনা):** সমস্যা রিপোর্ট, ইউনিক টিকিট কোড (`TKT-2026-xxxx`), এসাইনমেন্ট, রেজোলিউশন সামারি, রি-ওপেনিং সুবিধা, কমেন্ট থ্রেড এবং টিকিট প্রিন্ট।
3. **IT Asset Management (কম্পিউটার, প্রিন্টার ও স্ক্যানার ইনভেন্টরি):** কম্পিউটার, ল্যাপটপ, প্রিন্টার (টোনার ও পেজ কাউন্টার), স্ক্যানার, সুইচ, রাউটার ও সিসিটিভি ইনভেন্টরি, স্থানান্তর ইতিহাস এবং প্রিন্টযোগ্য SVG QR কোড ব্যাজ।
4. **Network & Internet Management (নেটওয়ার্ক ও আইপিএম):** কোর সুইচ, রাউটার, এক্সেস পয়েন্ট, আইপি অ্যাড্রেস বরাদ্দ (IPAM - কনফ্লিক্ট প্রিভেনশন), আইএসপি কানেক্টিভিটি এবং লোকাল নেটওয়ার্ক টপোলজি সামারি।
5. **CCTV & Security Equipment (সিসিটিভি ও সিকিউরিটি):** আইপি ও অ্যানালগ ক্যামেরা, এনভিআর চ্যানেল, স্টোরেজ রিটেনশন, সাপ্তাহিক শারীরিক পরিদর্শন লগ এবং ত্রুটির জন্য ১-ক্লিক টিকিট তৈরি।
6. **Hospital Software & Licenses (সফটওয়্যার ও লাইসেন্স):** এইচএমএস, ডাটাবেজ, অ্যান্টিভাইরাস লাইসেন্স ট্র্যাকিং, এক্সপায়ারি অ্যালার্ট এবং মাস্কড কি প্রটেকশন।
7. **Backup Management (ব্যাকআপ রেজিস্টার):** ওরাকল ডাটাবেজ, পিএসিএস ও একাউন্টস ব্যাকআপের দৈনিক ম্যানুয়াল লগ, ভেরিফিকেশন ট্র্যাকিং এবং ব্যর্থ ব্যাকআপের ক্ষেত্রে ফলো-আপ অ্যালার্ট।
8. **Maintenance & Task Schedule (রক্ষণাবেক্ষণ শিডিউল):** দৈনিক, সাপ্তাহিক, মাসিক প্রতিরোধমূলক রক্ষণাবেক্ষণ চেকলিস্ট (ইন্টারেক্টিভ চেকবক্স), ওভারডিউ ট্র্যাকিং এবং সার্ভিসিং নোট।
9. **Staff, Departments & Access (স্টাফ ও ডিপার্টমেন্ট ডিরেক্টরি):** হাসপাতালের ১০টি বিভাগ, আইটি ফোকাল পয়েন্ট স্টাফ এবং ডেমো রোল প্রিভিউ।
10. **Knowledge Base & SOP (আইটি নলেজ বেস):** প্রিন্টার কনফিগারেশন, স্ক্যানার রিসেট, ব্যাকআপ ভেরিফিকেশন এসওপি এবং কি-ওয়ার্ড অনুসন্ধান।
11. **Expenses, Purchases & Vendors (খরচ ও ভেন্ডর ব্যবস্থাপনা):** আইটি সামগ্রী রিকোয়েস্ট (`PR-2026-xxxx`), ভাউচার খরচ রেজিস্টার এবং অনুমোদিত প্রযুক্তি ভেন্ডর ডিরেক্টরি।
12. **Reports & Analytics (রিপোর্ট ও অ্যানালিটিক্স):** টিকিট, অ্যাসেট, ব্যাকআপ, ব্যয় ও ডিপার্টমেন্টভিত্তিক ১২টি কমপ্লায়েন্স রিপোর্ট, ফিল্টারিং, প্রিন্ট প্রিভিউ এবং Excel-সামঞ্জস্যপূর্ণ CSV ডাউনলোড।
13. **Notification Center (ইন-অ্যাপ নোটিফিকেশন):** লোকাল ডেটার ভিত্তিতে জরুরি টিকিট, ওভারডিউ টাস্ক, এক্সপায়ার হতে যাওয়া লাইসেন্স ও ব্যাকআপ ওয়ার্নিংয়ের অ্যালার্ট সেন্টার।
14. **Settings & System Administration (সেটিংস ও ডেটা ম্যানেজমেন্ট):** হাসপাতালের প্রোফাইল এডিটর, লোকাল অডিট অ্যাক্টিভিটি হিস্টোরি, স্টোরেজ ব্যবহার, JSON ব্যাকআপ ডাউনলোড, JSON রিস্টোর এবং ১-ক্লিক ডেমো ডেটা রিসেট।

## 4. GitHub Pages Deployment (গিটহাব পেজেস ডিপ্লয়মেন্ট)

এই প্রজেক্টটি কোনো সার্ভার বা বিল্ড টুল ছাড়াই সরাসরি GitHub Pages-এ পাবলিশ করা যায়।

### ডিপ্লয়মেন্টের ধাপসমূহ:
1. প্রজেক্টের সব ফাইল GitHub রিপোজিটরির `main` ব্রাঞ্চে পুশ করুন।
2. রিপোজিটরির **Settings** ট্যাবে যান।
3. বাঁপাশের মেনু থেকে **Pages** নির্বাচন করুন।
4. **Build and deployment** সেকশনে **Source** হিসেবে **Deploy from a branch** সিলেক্ট করুন।
5. Branch হিসেবে **`main`** এবং ফোল্ডার হিসেবে **`/(root)`** নির্বাচন করে **Save** বাটনে ক্লিক করুন।
6. গিটহাব একশন রান সম্পন্ন হলে Settings > Pages-এ প্রকাশিত URL দেখতে পাবেন:
   ```text
   https://<username>.github.io/<repository-name>/
   ```
7. URL-টিতে প্রবেশ করে পোর্টালটি ব্যবহার করুন।

## 5. Local Running & Browser Security (লোকাল প্রিভিউ ও নির্দেশিকা)

আধুনিক ব্রাউজারগুলো (Google Chrome, Microsoft Edge, Firefox) নিরাপত্তার কারণে সরাসরি লোকাল ফাইল সিস্টেম (যেমন: ফাইলে ডাবল-ক্লিক করে `file:///` প্রোটোকল) থেকে জাভাস্ক্রিপ্ট **ES Modules** লোড করতে বাধা দেয় (CORS Restriction)।

অতএব, লোকাল কম্পিউটারে রান করার জন্য যেকোনো একটি সাধারণ লোকাল সার্ভার ব্যবহার করুন:

1. **VS Code Live Server (সবচেয়ে সহজ):**  
   VS Code-এ ফোল্ডারটি ওপেন করে `index.html` ফাইলে রাইট-ক্লিক করে **"Open with Live Server"** চাপুন।
2. **Node.js (npx serve):**  
   টার্মিনালে প্রজেক্ট ফোল্ডারে রান করুন:
   ```bash
   npx serve .
   ```
3. **Python Simple HTTP Server:**  
   টার্মিনালে রান করুন:
   ```bash
   python -m http.server 8080
   ```
   এরপর ব্রাউজারে প্রবেশ করুন: `http://localhost:8080`
4. **GitHub Pages:**  
   GitHub-এ পুশ করলে কোনো সার্ভার ছাড়াই এটি সরাসরি সম্পূর্ণ গতিতে লাইভ চলবে।

> [!NOTE]
> যদি কেউ অসাবধানতাবশত সরাসরি `file:///` দিয়ে `index.html` ওপেন করেন, অ্যাপ্লিকেশনটি অনন্তকাল স্পিনার ঘুরিয়ে আটকে থাকবে না—পরিবর্তে স্বয়ংক্রিয়ভাবে একটি নির্দেশিকামূলক অ্যালার্ট কার্ড প্রদর্শিত হবে। এছাড়া কোনো ব্রাউজারে অপ্রত্যাশিত স্টার্টআপ বিলম্ব ঘটলে ৫ সেকেন্ডের সক্রিয় ওয়াচডগ ডায়াগনস্টিক রিকভারি অপশন প্রদর্শন করে।

## 6. Data Storage & Portability (ডেটা সংরক্ষণ ও ব্যাকআপ)

- **IndexedDB:** হাসপাতালের সকল টিকিট, সরঞ্জাম, আইপি, ব্যাকআপ লগ ও চেকলিস্ট ব্রাউজারের IndexedDB ডেটাবেজে সংরক্ষিত থাকে।
- **LocalStorage:** ব্যবহারকারীর ভাষা পছন্দ (Bangla/English), থিম (Light/Dark) ও রোল প্রিফারেন্সের জন্য ব্যবহৃত।
- **JSON Backup Export:** Settings মেনু থেকে ১-ক্লিকে সম্পূর্ণ ডেটাবেজের টাইমস্ট্যাম্পযুক্ত JSON ফাইল ডাউনলোড করা যায়।
- **JSON Backup Restore:** যেকোনো সময় ডাউনলোডকৃত JSON ব্যাকআপ ফাইল ইমপোর্ট করে ডেটা হুবহু রিস্টোর করা যায়।
- **CSV Export:** টিকিট, অ্যাসেট, ব্যয় এবং ১২টি রিপোর্টের জন্য Excel-উপযোগী UTF-8 BOM যুক্ত CSV এক্সপোর্ট সুবিধা রয়েছে।

## 7. Privacy, Security & Demo Role Disclaimers (সীমাবদ্ধতা ও সতর্কতা)

1. **কোনো আসল রোগীর তথ্য নয়:** এটি হাসপাতাল আইটি ডিপার্টমেন্টের অভ্যন্তরীণ পোর্টাল। কোনো রোগীর ক্লিনিক্যাল বা মেডিকেল তথ্য এখানে ইনপুট দেওয়া নিষিদ্ধ।
2. **গোপন তথ্য পরিহার:** আসল পাসওয়ার্ড, ওয়াই-ফাই কি বা সিসিটিভি ক্রেডেনশিয়াল ব্রাউজারে সংরক্ষণ করবেন না।
3. **ডেমো রোল প্রিভিউ:** সুপার অ্যাডমিন, আইটি অফিসার বা স্টাফ রোলে সুইচ করার সুবিধাটি শুধুমাত্র ইউআই ও ওয়ার্কফ্লো প্রদর্শনের জন্য। এটি সার্ভার-এনফোর্সড অথেনটিকেশন নয়।
4. **ক্লায়েন্ট-সাইড প্রোটোটাইপ:** এটি একটি সিঙ্গেল-ব্রাউজার অপারেশনাল প্রোটোটাইপ। মাল্টি-কম্পিউটার সেন্ট্রাল সিঙ্ক বা অটোমেটেড ব্যাকআপ নিশ্চিত করার জন্য পরবর্তী পর্যায়ে সার্ভার ইন্টিগ্রেশন প্রয়োজন।
